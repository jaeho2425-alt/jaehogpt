# NotchConvert 0.3.1 검증 결과

설치 후 앱을 열어도 창이 나타나지 않던 문제를 수정했습니다. 첫 실행에서 변환 창을 표시하고, 이미 실행 중인 앱을 Finder에서 다시 열면 접어 둔 창을 다시 표시합니다.

- 빌드·설치·창 열기 검사: https://github.com/jaeho2425-alt/jaehogpt/actions/runs/39275963892
- 설치 파일: https://github.com/jaeho2425-alt/jaehogpt/releases/tag/test-4
- 앱 소스 커밋: 8f4e79c42c4e4d39317a563afb6422b0494f171b

## 통과한 검사

Apple Silicon과 Intel Mac 서버에서 Swift 컴파일, 공통 변환 처리 테스트 52개, 내장 실행 파일의 아키텍처·최소 macOS 버전·의존 라이브러리·서명 검증을 통과했습니다. 내장 엔진의 PDF/JPEG/PNG 코덱, PPTX 사본, ZIP 원본 복원, 한글·공백 경로, 원본 옆 저장도 확인했습니다.

생성한 PKG를 실제 /Applications에 설치한 뒤 설치된 엔진과 서명을 다시 검사했습니다. Launch Services로 설치된 앱을 실행하고, 내용과 크기가 있는 변환 창이 화면 영역에 표시되는지 검사했습니다. 같은 창을 접기 버튼과 동일한 방식으로 숨긴 뒤 외부에서 앱을 다시 열어 창이 표시되는지 확인했습니다. 양쪽 Mac에서 두 단계 모두 통과했습니다. 이전의 프로세스 실행 여부만 확인하는 검사를 창 표시 검사로 교체했습니다.

두 설치 파일을 내려받아 ZIP CRC·아카이브 SHA-256·XAR 패키지 헤더를 검사하고, PKG SHA-256이 빌드 서버의 체크섬 및 릴리스 자산의 값과 일치함을 확인했습니다.

## 사용 및 남은 검사

업데이트 전에는 실행 중인 기존 앱을 메뉴 막대의 원형 화살표 아이콘 → 종료로 닫아 주세요. PKG를 더블클릭해 설치한 후 응용 프로그램의 NotchConvert를 열면 변환 창이 나타납니다. Python이나 개발 도구는 필요하지 않습니다.

Keynote가 서버에 없어 실제 문서 내보내기 검사 15개는 건너뛰었습니다. 실제 Keynote 변환, 문서별 글꼴·레이아웃, Shift 드래그·원형 메뉴 드롭·노치 접근, 사용자 Mac의 자동화 권한은 별도로 확인해야 합니다. 이번 창 열기 검사의 통과가 모든 변환과 드래그 기능의 검증을 뜻하지는 않습니다.

macOS 13 이상이 필요합니다. Apple 공증과 Developer ID 서명은 적용하지 않은 테스트 버전입니다.
